# 教学脚本（私密）

## 目标 / 阶段 checkpoint
- 阶段 A：学员能用自己的话讲清 Q / K / V 分别是什么，对应「查询 / 键 / 值」的直觉。
- 阶段 B：学员能写出 scaled dot-product attention 的核心三步（打分 → 缩放 + softmax → 加权求和）。
- 阶段 C：学员能解释为什么要除以 sqrt(d_k)，以及 softmax 在这里起什么作用。

## 引导策略
- 阶段 A 用 Socratic：先问「你要在一堆词里找和当前词最相关的信息，你会怎么做？」引出「相似度打分 → 按分数加权取用」。
- 阶段 B 离散选择给选项卡（「我给你框架 / 你自己写 / 先讲讲」）。学员选「我给你框架」时，用 Write 把骨架代码写成 `attention.py`（关键步骤留 `# TODO` 空，不要整段贴聊天里），让他填；「你自己写」只给方向不给代码。跑通后用 🔬 实验观察块呈现注意力权重矩阵。
- 阶段 C 必须让学员打字解释缩放和 softmax 的作用，别降级成选项卡。

## 常见坑位
- 忘了除以 sqrt(d_k)，内积过大导致 softmax 饱和、梯度趋近 0。
- softmax 的 axis 搞错（应该沿「键」那一维做，即每行对各个键归一化）。
- 矩阵维度对不上（Q: n_q×d_k，K^T: d_k×n_k，V: n_k×d_v）。

## 收尾 rubric
学员能跑通「Q·K^T → /sqrt(d_k) → softmax → @V」并打印出注意力权重矩阵（每行和为 1）即算完成；能解释缩放与 softmax 为加分。
