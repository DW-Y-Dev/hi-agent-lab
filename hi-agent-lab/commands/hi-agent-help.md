列出本插件的命令清单，简短说明每个的用途：

- `/hi-agent` —— 主入口：列出所有 lab + 当前进度，选一个开始
- `/hi-agent-start [lab_id]` —— 开始一个 lab（注入 Mentor 人格 + 教学脚本）
- `/hi-agent-status` —— 显示当前 lab 进度
- `/hi-agent-review` —— 提交一次 review（反思 + 代码快照 → 本地 reviews/）
- `/hi-agent-help` —— 本清单
